# 名刺管理（社内専用）

営業でもらった名刺を、会社名・氏名・「いつ、どこで会い、何を話したか」で検索できる個人用Webアプリです。
スマホ・PCのブラウザから社内のアプリサーバーに接続し、データと画像は**社内の共有フォルダ**に保存します。

```
スマホ / PC のブラウザ ──(社内LAN・社内Wi-Fi・既存VPN)──▶ アプリサーバー（社内Windows PC） ──▶ 共有フォルダ（UNCパス）
```

- 外部クラウド（DB・認証・ストレージ・OCR・生成AI）、CDN、外部フォント、解析サービスを使いません。実行時に外部へ通信しません。
- サーバー実行時の依存パッケージはありません（Node.js 本体のみ）。OCR エンジンと日本語データもアプリに同梱し、社内サーバーから配信します。
- ソフトウェア費用は0円です（Node.js・Tesseract.js はオープンソース）。

## できること

- 名刺の登録・編集（表裏画像、会社名、部署・役職、氏名・ふりがな、電話・携帯、メール、住所、Web、交換日、場所・イベント、分類、タグ、メモ）
- スマホでの撮影／画像選択、回転・差し替え・削除、縮小と位置情報などメタデータの除去、失敗時の再試行
- 端末内OCR（任意）：読み取り → 候補表示 → 本人が確認・修正 → 保存（自動保存はしません）
- 横断検索（ひらがな・カタカナ・全角半角を区別しない AND 検索）、分類・イベント・タグ絞り込み、並べ替え
- 重複候補の注意表示（自動統合しません）
- 同時編集の検出（古い内容での無言の上書きを防止）
- 自動バックアップ（画像込み・世代管理）、手動バックアップ、検証付き復元（復元前のデータは自動退避）
- Excel 用 CSV 出力（UTF-8 BOM付き、数式注入対策、電話番号の先頭0保持）

## 開発

Node.js 20.11 以上（推奨 22 LTS）。

```bash
npm ci
```

```bash
npm run build
```

```bash
npm run typecheck
```

```bash
npm test
```

開発用の保存先は `init-store --dev` で作成し、架空データは `node dist/server/cli.js seed-dev` で投入します（`--dev` で作った保存先以外には投入できません）。
ブラウザでの通し確認は `scripts/e2e-check.mjs`（Playwright が必要。架空の名刺画像をその場で生成して使います）。

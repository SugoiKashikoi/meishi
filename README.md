# 名刺管理（社内デスクトップアプリ）

営業でもらった名刺を、会社名・氏名・「いつ、どこで会い、何を話したか」で検索できる、社内向けのWindowsデスクトップアプリです。
各PCにインストールしたアプリが、**社内の共有フォルダ**のデータを直接読み書きします。複数人で同じ名刺データを共有できます。

```
各PCの名刺管理アプリ ──(社内LAN・既存の共有フォルダ)──▶ 共有フォルダ（UNCパス）
```

- **サーバーもポートも使いません。** 外部クラウド（DB・認証・ストレージ・OCR・生成AI）、CDN、外部フォント、解析サービスへの通信もしません（アプリ内で外部への通信を遮断）。
- OCR エンジンと日本語データもアプリに同梱しています。ソフトウェア費用は0円です。
- スマホからは直接使えません。スマホや複合機でスキャンした名刺は、取り込み用フォルダ経由でPCから登録します。

## できること

- 名刺の登録・編集（表裏画像、会社名、部署・役職、氏名・ふりがな、電話・携帯、メール、住所、Web、交換日、場所・イベント、分類、タグ、メモ）
- 画像・PDF の取り込み（ファイル選択・ドラッグ＆ドロップ。スキャン PDF は 1ページ目＝表、2ページ目＝裏）、回転・差し替え・削除、縮小と位置情報などメタデータの除去
- 端末内OCR：読み取り → 候補表示 → 本人が確認・修正 → 保存（自動保存はしません）
- AI での一括登録（任意）：Codex / Claude Code が取り込み用フォルダの画像を読み、AI専用フォーム（JSON）を作って `ai-add` コマンドで直接登録（アプリの画面を通さないが、保存処理はアプリと同じ。タグ「AI入力」付き）
- 取り込み用フォルダ：複合機のスキャン等を「未整理」として表示し、確認して登録（元ファイルは取り込み済みへ移動。PDF はページごとに分割）
- 一覧：名刺画像つき・名刺交換月ごとの表示、横断検索（ひらがな・カタカナ・全角半角を区別しない）、分類・イベント・タグ絞り込み、並べ替え
- 登録者・更新者の記録（Windowsユーザー）、重複候補の注意表示（自動統合しません）
- 複数PCでの同時編集の検出（古い内容での無言の上書きを防止）
- 自動バックアップ（画像込み・世代管理）、手動バックアップ、検証付き復元（復元前のデータは自動退避、復元中は他のPCの保存を停止）
- Excel 用 CSV 出力（UTF-8 BOM付き、数式注入対策、電話番号の先頭0保持）

## 開発

Node.js 22.12以上が必要です（このクラウドでは24.22.1で検証）。

```bash
npm ci
```

```bash
npm run typecheck
```

```bash
npm test
```

```bash
npm start
```

インストーラーの作成（Windows で実行。`release/` に出力）：

```bash
npm run dist:win
```

- デスクトップ版の通し確認：`xvfb-run -a node scripts/e2e-desktop.mjs <作業フォルダ>`（Playwright が必要。架空の名刺画像・PDF をその場で生成して使います）
- `src/server/devserver.ts` は開発・自動テスト専用（127.0.0.1 のみ）。配布版には含めません。

- [docs/検証とOCR評価.md](docs/検証とOCR評価.md) — 障害対策、OCR比較、残る検証項目

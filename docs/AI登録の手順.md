# AI で名刺を登録する手順（Codex / Claude Code 向け）

この文書は、利用者の PC で動く AI（ChatGPT の Codex、Claude Code など）に渡して使います。
AI が取り込み用フォルダの名刺画像を読み、**AI専用フォーム**（JSON）を作り、**直接登録コマンド**で保存データへ登録します。アプリの画面は使いません。

## 利用者がやること

1. 名刺画像（JPEG または PDF）を取り込み用フォルダに入れる（複合機のスキャン等）。
2. このリポジトリ（`meishi`）のフォルダで、Codex または Claude Code を起動する（事前に `npm ci` と `npm run build:main` を済ませておく）。
3. 次のように頼む（パスは自分の環境に合わせる）。

```text
docs/AI登録の手順.md を読んで、その手順どおりに名刺を登録して。
保存先は \\fileserver\share\meishi、取り込み用フォルダは \\fileserver\share\meishi-inbox。
```

4. 終わったらアプリを開き、タグ「AI入力」の名刺を確認・修正する。

> **注意**：名刺画像（取引先の個人情報）が AI の提供元（OpenAI / Anthropic）に送信されます。社内のルールで認められている場合だけ使ってください。個人アカウントの場合は、学習に使わない設定（ChatGPT：データ コントロール →「すべての人のためにモデルを改善する」をオフ）にしてください。

## AI への指示（ここから下を守って作業すること）

### やること

1. 取り込み用フォルダの `.jpg` `.jpeg` `.pdf` を一覧にする（`.tmp-` で始まるもの、隠しファイルは対象外）。
   - PDF は1ページ目＝表、2ページ目＝裏として扱われる。1つの PDF に複数の名刺が入っている場合は、登録せずに利用者へ報告する。
   - 表と裏が別ファイルになっていると判断できる場合は、1件の名刺としてまとめる（判断できなければ別々の名刺として扱わず、利用者に確認する）。
2. 各画像を見て、名刺1枚ごとに下の「AI専用フォーム」を埋める。
   - **写真は名刺の部分だけを切り抜いて保存する。** 机や背景、指、他の書類が写っている場合は、名刺の四隅がすべて入る範囲を `frontCrop` / `backCrop` に指定する（画像の幅・高さに対する割合 0〜1。名刺の外側に1〜2%の余白を取る）。
   - 名刺が横向き・逆さまに写っている場合は、文字が正しい向きになるよう `frontRotate` / `backRotate` を指定する（時計回りに 90・180・270）。切り抜き範囲は回転前の元画像に対して指定する。
   - 複合機のスキャンなど、すでに名刺だけの画像は切り抜き不要（`frontCrop` は `null`）。作業用フォルダ（例：`%TEMP%\meishi-ai\`）に `form.json` として、全件を配列で保存する。
3. まず試し実行して、エラーと重複候補を確認する。

```bash
node dist/server/cli.js ai-add --data "<保存先>" --inbox "<取り込み用フォルダ>" --json "<作業用フォルダ>\form.json" --dry-run --preview "<作業用フォルダ>\preview"
```

   - `preview` フォルダに、切り抜き・回転後の画像（`1-front.jpg`、`1-back.jpg` …）が書き出される。**必ずすべて開いて確認する。** 名刺が欠けている・背景が大きく残っている・向きが違う場合は、フォームの範囲や回転を直して試し実行をやり直す。

4. エラーが無ければ本番で登録する（`--dry-run` を外す）。
5. 結果（JSON）を見て、次を利用者に日本語で報告する。
   - 登録できた件数と、会社名・氏名
   - 失敗した名刺とその理由
   - `duplicates` が空でないもの（既に登録済みかもしれない名刺）
   - 読み取りに自信が無い項目
6. 作業用フォルダ（`form.json` と `preview`）を削除する（個人情報を残さない）。

### 守ること

- **保存先フォルダ（cards / images / trash など）のファイルを直接作成・編集・削除しない。** 登録は必ず `ai-add` コマンドで行う（ロック・検証・二重登録防止がかかるため）。
- 取り込み用フォルダのファイルは、`ai-add` が登録後に自動で取り込み済みへ移す。自分で移動・削除しない。
- 名刺に書かれていないことを推測で埋めない。読めない項目は `""` にする。
- `memo` は利用者から指示があったときだけ書く（名刺から読めない情報を作らない）。
- 名刺の内容をこの作業以外の目的で使わない。外部のサービスやファイルに書き出さない。
- 既存の名刺の修正・削除はしない（アプリで人が行う）。

### AI専用フォーム

`node dist/server/cli.js ai-form` でもひな形を表示できる。

```json
[
  {
    "company": "会社名（会社名か氏名のどちらかは必須）",
    "department": "部署",
    "title": "役職",
    "name": "氏名（姓と名の間は半角スペース）",
    "kana": "ふりがな（ひらがな。名刺に無ければ空）",
    "phone": "電話番号",
    "mobile": "携帯番号",
    "email": "メールアドレス",
    "postalCode": "郵便番号（123-4567）",
    "address": "住所（郵便番号を除く）",
    "website": "Webサイト",
    "exchangeDate": "名刺交換日（YYYY-MM-DD。分からなければ空）",
    "place": "会った場所",
    "event": "イベント名",
    "category": "分類（顧客／見込み客／仕入先／協力会社／その他、または空）",
    "tags": [],
    "memo": "",
    "frontImageFile": "表面の画像ファイルのパス（JPEG または PDF）",
    "frontCrop": { "left": 0.1, "top": 0.2, "width": 0.8, "height": 0.55 },
    "frontRotate": 0,
    "backImageFile": "裏面の画像ファイルのパス（任意）",
    "backCrop": null,
    "backRotate": 0
  }
]
```

- 画像は JPEG か PDF のみ（PNG・HEIC は不可。利用者に JPEG での保存を頼む）。
- 切り抜き範囲：`left`・`top` は名刺の左上の位置、`width`・`height` は名刺の幅・高さ。いずれも元画像の幅・高さに対する割合（0〜1）。例：画像の中央に横幅の80%で写っていれば `left: 0.1, width: 0.8`。
- 切り抜き・回転には、このフォルダの Electron（`npm ci` で入る）を使う。保存される画像は長辺2000pxまでに縮小され、撮影位置などのメタデータは含まれない。
- 登録した名刺には自動でタグ「AI入力」が付き、登録者は PC の Windows ユーザーになる。
- 結果の終了コード：0＝全件成功、2＝失敗あり（成功した分は登録済み）。

# Windows 11 x64 ローカル運用セット

アプリとAI登録コマンドは自分のPCで実行し、名刺データだけ社内共有フォルダへ保存します。
Node.js・Electron・OCRデータを同梱しているため、PC側のnpm実行・ビルド・APIキー設定は不要です。

## 最初の起動

1. 既存アプリで手動バックアップを保存し、全PCの旧版アプリ・AI登録コマンドを終了します。
2. ZIPを「すべて展開」で C:\Tools\MeishiKanri など自分のPCへ展開します。ZIP内・共有フォルダから直接実行しません。
3. Verify.cmd で配布ファイルの整合性を確認します。
4. meishi-config.json の dataDir と inboxDir が、アプリに表示されているパスと一致するか確認します。
5. Check.cmd で接続確認します。既存の保存先だけを確認し、初期化・ダミーデータ投入はしません。
6. Start.cmd で起動します。既存のPC設定がある場合は、アプリはそちらを優先します。管理画面で保存先と取り込み用フォルダを確認してください。

初期化済みなのに初期化を求められた場合は、その操作をせずパスと共有ドライブへの接続を確認します。
既存データを手動で削除・上書きする必要はありません。

共有ドライブは、そのドライブを使える通常のWindowsユーザーで実行します。管理者として起動するとドライブが見えない場合があります。
Windowsや社内管理のポリシーで実行が止められた場合は、警告を無効化せず、配布元・ハッシュ・社内での実行許可を確認してください。

## 名刺1枚で試す

1. 表面のJPEG写真1枚を、設定済みの取り込み用フォルダへ入れます。
2. PC上でファイル操作できるCodexを、この展開フォルダで開きます。
3. AI-REQUEST.txt の依頼文を渡します。
4. Codexはまず AI.cmd dry-run で登録候補と切り抜き画像を作ります。初回は内容を確認してから AI.cmd register で登録します。
5. 登録後はアプリで内容を確認します。裏面は必要な場合だけ追加します。

通常のChatGPTのWeb画面だけでは、PCや共有フォルダへ直接保存できません。
Codex側のログイン・ネット接続は必要です。アプリへのAPI組み込みはありませんが、Codexに読ませた写真はクラウドで処理されます。
写真を外部へ送らない場合は、アプリ内の端末内OCRを使います。

登録成功後の元写真はコマンドが dataDir\inbox-done へ移します。失敗した写真は元の場所に残します。
移動だけが失敗した場合は名刺が登録済みの場合があるため、アプリで確認してから対処します。
取り込み済み原本は設定の保持日数（標準90日）を過ぎると削除対象です。アプリが保存した名刺画像は別途保持します。

フォーム・プレビューはPC上の work に置き、登録後に今回の作業ファイルだけを片付けます。
meishi-config.json と work/ は編集対象のため、配布ファイルのハッシュ検証から除外しています。

## 検証の範囲

ZIPはLinuxで作成したWindows x64向け配布物です。Node・Electronの公式チェックサム、実行ファイルの形式、配布内容を確認しています。
Windows実機と実際の社内共有フォルダへの接続は、このPCで確認する必要があります。
旧版と新しいロック方式を混在させないでください。残留ロックの復旧は docs/導入手順.md を参照します。

# 導入手順（デスクトップアプリ・共有フォルダ）

## 0. 構成

```
各PCの名刺管理アプリ（インストール型） ──▶ 社内の共有フォルダ（例 \\fileserver\share\meishi）
```

- アプリは各PCで動き、共有フォルダのファイルを直接読み書きします。**サーバー、ポートの開放、ファイアウォールの変更は不要です。**
- インターネット接続は不要です。アプリは外部へ一切通信しません。
- 共有フォルダに繋がっていないPC（社外など）では使えません。社外から使う場合は、会社で認められた既存のVPNで共有フォルダに繋がっているときに限ります。
- スマホからは直接使えません（6. を参照）。

## 1. インストーラーを用意する（1回だけ）

インターネットに接続できる開発用の Windows PC で、次を実行します。

```bash
npm ci
```

```bash
npm run dist:win
```

`release/` に `MeishiKanri Setup <版>.exe` ができます。これを社内の共有フォルダなどに置いて配布します。各PCに Node.js などを入れる必要はありません。

- インストーラーは**利用者ごとのインストール（管理者権限不要）**です。
- インストーラーにはコード署名をしていないため、初回実行時に Windows の SmartScreen が警告を出すことがあります。社内で配布してよいか、情報システム担当者に確認してください。

## 2. 共有フォルダを用意する（管理者が1回だけ）

| フォルダ | 用途 | 付与する権限 |
|---|---|---|
| `\\fileserver\share\meishi` | 名刺データ・画像・バックアップ（`backups`）・取り込み済み画像（`inbox-done`） | 名刺管理を使う人のグループ（例 `CORP\名刺管理利用者`）：**変更** |
| `\\fileserver\share\meishi-inbox`（任意） | 取り込み用フォルダ（複合機のスキャン等を置く） | 同じグループ：**変更**。複合機のスキャン用アカウント：**書き込み** |
| 上記フォルダのその他の人 | — | **アクセス権なし**（Everyone / Domain Users は外す） |

- 名刺は個人情報です。**このフォルダにアクセスできる人は、アプリを使わなくてもデータを読めます。** 権限は利用者のグループだけに絞ってください。
- アプリは保存先フォルダ内で、ファイルの作成・置き換え（rename）・削除と、サブフォルダの入れ替え（復元時）を行います。「変更」権限が必要です。
- マップドライブ（Z: など）より UNC パス（`\\サーバー名\共有名\...`）を推奨します。
- 保存先フォルダの中身は、エクスプローラーで直接編集・移動しないでください（アプリが管理します）。

## 3. 初回設定

1. アプリを起動すると「保存先の設定」画面が出ます。
2. **保存先フォルダ**に `\\fileserver\share\meishi` を入力します（「参照…」でも選べます）。
3. 取り込み用フォルダを使う場合は、**取り込み用フォルダ**に `\\fileserver\share\meishi-inbox` を入力します。
4. **表示名**（登録者として他の人に表示される名前）を確認して「この設定で開始」を押します。
5. **最初の1人だけ**：フォルダがまだ保存先になっていないので「このフォルダを保存先として初期化する」が出ます。押すと初期化されます。2人目以降は、同じフォルダを指定すればすぐに使えます。

- 設定は各PC・各利用者の `%APPDATA%\MeishiKanri\settings.json` に保存されます（共有フォルダには置きません）。
- 全員の初期値をそろえたい場合は、`meishi-config.sample.json` を参考に `meishi-config.json` を作り、アプリ（`MeishiKanri.exe`）と同じフォルダに置くと、初回の入力欄にあらかじめ値が入ります。

## 4. 使い方

- **登録**：「＋ 新規登録」→ 表面・裏面に画像または PDF を「選択」するか、ドラッグ＆ドロップ →（任意）「文字を読み取る」で候補を確認して反映 → 内容を確認して「保存」。
  - スキャン PDF を選ぶと、1ページ目が表、2ページ目が裏になります。
  - 会社名か氏名のどちらかがあれば保存できます。
- **一覧・検索**：名刺画像つきで、名刺交換月ごとに表示します。会社名・氏名・部署・メモ・タグを横断して検索できます。
- **未整理**：取り込み用フォルダに置いた画像・PDF を一覧表示します。1〜2枚選んで「選んだ画像で登録」（1枚目＝表、2枚目＝裏）。登録や破棄をすると、元のファイルは取り込み済みへ移ります（90日後に削除）。「＋ ファイルを追加」でPC内のファイルを取り込み用フォルダへ送ることもできます。
- **複合機**：「フォルダへスキャン」の保存先を取り込み用フォルダにし、形式は JPEG または PDF、300dpi 程度を推奨します。
- **登録者の表示**：名刺には登録者・最終更新者（Windowsユーザーと表示名）を記録し、詳細画面に表示します。
- **同時編集**：別のPCで先に更新された名刺を古い画面から保存しようとすると、差分を表示して止まります（無言で上書きしません）。

## 5. バックアップ・復元

- **自動バックアップ**：起動中のアプリのどれか1台が、1時間ごとに確認し、前回から24時間経っていれば画像込みの全件バックアップを `保存先\backups` に作ります（14世代を保持）。間隔と世代数は `meishi-config.json` の `autoBackup` で変更できます。
- **手動バックアップ**：「管理」→「今すぐバックアップを作成」。「ダウンロード」で任意の場所に保存できます。
- **同じ共有ストレージ（同じ NAS）内のバックアップでは、NAS 自体の故障・ランサムウェア・誤削除には備えられません。** 定期的に（例：月1回）バックアップをダウンロードし、会社の規程に沿った別の社内媒体にも保管してください。
- **復元**：「管理」→ 一覧の「この時点に復元」または「バックアップファイルを選んで検証」。形式・ハッシュ・画像の参照を検証し、件数を確認してから「復元」と入力して実行します。
  - 実行前のデータは「復元前の退避」バックアップとして自動保存されます。
  - 復元中は、他のPCの保存が「復元作業中」として止まります（終わったらもう一度保存できます）。
- **CSV出力**：「管理」→「CSVをダウンロード」。Excel で開けます。**画像は含まれません。**
- 削除した名刺は `保存先\trash` に削除時点のデータが残ります（画像も保持）。

## 6. スマホでスキャンした名刺

スマホからアプリは使えないため、スキャンした画像・PDF を取り込み用フォルダ（またはPC）に移してから登録します。

- **iCloud に保存しないこと。** iPhone の「メモ」や「写真」は標準で iCloud に同期されるため、名刺画像が外部のクラウドに保存されます。
  - メモでスキャンする場合：設定 → メモ →「"このiPhone内"アカウント」をオンにし、そのアカウントのメモでスキャンします。
  - 写真（カメラ）で撮る場合：iCloud 写真がオフであることを確認します。
- **PCへの移し方は社内環境によります。**
  - USB 接続で Windows から見えるのは、基本的に「写真」の画像だけです（メモの PDF は直接見えません）。
  - iPhone の写真は HEIC 形式のことがあります。設定 → 写真 →「Mac または PC に転送」を「自動」にすると JPEG に変換されます。
  - 会社PCにスマホを接続してよいか、どの方法で移してよいかは、社内の規程に従ってください。
- 登録が済んだら、スマホ・PCに残った名刺画像は削除してください。
- 複合機や PC 用スキャナーで読み取る方が、手順が少なく確実です。

## 7. 更新・トラブル

| 状況 | 対処 |
|---|---|
| 新しい版を入れる | 新しいインストーラーを実行（データは共有フォルダにあるので影響しません）。念のため事前に手動バックアップを作成 |
| 画面上部に「保存先（共有フォルダ）に接続できません」 | ネットワーク・NAS・権限を確認。復旧すると30秒以内に自動で再接続します。切断中の保存は失敗として表示され、入力内容は画面に残ります |
| 起動時に「保存先にアクセスできないか、初期化されていません」 | 共有フォルダに繋がっているか確認して「再接続」。別のフォルダを指定してしまった場合は、正しいフォルダを指定し直す |
| 「他のPCが同じデータを処理中です」 | 数秒待ってからもう一度保存。PCが途中で止まった場合も、30秒経てば自動で解除されます |
| 一部の名刺が一覧に出ない | 読み込めないファイルは一覧から除外し、ログ（`%APPDATA%\MeishiKanri\logs`）に記録しています。該当名刺はバックアップから復元してください |
| PCを入れ替えた | アプリをインストールして、同じ保存先フォルダを指定するだけ（データ移行は不要） |

## 8. 情報システム担当者に確認しておくとよいこと

- 署名なしのインストーラー（利用者ごとのインストール）を社内で使ってよいか
- 共有フォルダの作成と、利用者グループへの権限付与（2. の表）
- 共有フォルダのスナップショット・別媒体へのバックアップの有無
- 個人情報（名刺）を共有フォルダに保存する運用が社内規程上問題ないか
- スマホでスキャンした名刺をPCへ移す方法（6.）
